# Momentum OS 🚀

A personal productivity operating system built to maximize the odds of landing an **AI Full Stack Developer** job — not a timetable, a command center.

![Tech](https://img.shields.io/badge/React%2018-TypeScript-blue) ![Style](https://img.shields.io/badge/Tailwind-glassmorphism-8b5cf6) ![Charts](https://img.shields.io/badge/Recharts-stats-199e70)

## Features

- **Dashboard** — live clock, daily quote, animated progress ring, streak counter, quick-log counters, activity calendar, hype anthem player, and a **Dream Meter** (monthly applications, recruiters, interviews, offers → 🎯 Land AI Full Stack Job → 🇩🇪 Germany)
- **Daily Timetable** — 8 AM–10 PM timeline cards with checklists, live "Now" indicator, and weekday-rotating interview-prep focus
- **Interview Prep** — 10 topic cards (React, TypeScript, FastAPI, PostgreSQL, System Design, Docker, AWS, Redis, LangGraph, AI Agents), each with markdown notes
- **Job Tracker** — searchable / sortable / filterable table, funnel tiles, response rate, follow-up alerts
- **Goals** — daily & weekly targets with animated progress bars + 12 achievement badges
- **Stats** — area / bar / line charts (last 14 days) + application funnel, CVD-safe palette
- **Notes** — markdown editor with live preview and autosave
- **Pomodoro** — 25/5, 50/10, custom; auto break-switching, completion chime, tab-title countdown
- **Motivation** — reasons, dreams, and a fresh quote on every visit

### Extras

Confetti when all daily goals are met · keyboard shortcuts (`1`–`9` navigate, `t` theme, `s` sound) · dark/light mode · WebAudio sounds (zero assets) with mute toggle · everything persisted to localStorage · Framer Motion throughout.

## Stack

React 18 · TypeScript (strict) · Vite · Tailwind CSS · shadcn/ui-style primitives (Radix) · Framer Motion · Recharts · Lucide · React Router.

## Run it

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # type-check + production build
```

No backend, no accounts — your data lives in your browser's localStorage. Use **Load demo data** on any empty state to preview the app with 30 days of sample activity.
